# 对外文章草稿

本目录保存面向外部读者的文章草稿。发布平台可以重新排版，但事实、证据和决策引用以仓库版本为准。

每篇对外文章开头必须提供不超过 100 字的摘要，便于读者快速判断主题、问题与核心结论。

完整选题、证据、源码链接和定稿要求见[对外文章写作规范](./writing-guide.md)。

同系列草稿之间暂用仓库内相对链接；文章在掘金发布后，应替换为对应的公开文章 URL。
