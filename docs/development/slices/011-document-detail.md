## 目标

从知识库文章清单进入只读详情页，查看当前可检索正文、章节结构、历史版本和相关入库记录，不要求普通用户理解 snapshot、artifact 或数据库表。

## 输入与输出

输入：

- 当前 active snapshot 的文档清单；
- 文档 artifact 中的来源、章节和 blocks；
- 文档登记库中的版本记录；
- 与文档相关的持久化入库任务。

输出：

- `#knowledge/{doc_id}` 文档详情位置；
- 内容、版本与记录、技术信息三个页签；
- 章节导航和当前版本正文；
- 历史版本时间线与关联任务。

## 不包含

- 删除、改名、别名编辑和跨来源合并；
- 单篇历史版本恢复；
- 打开外部浏览器或文件管理器；
- 在详情页修改知识库数据。

## 验收条件

- [x] 知识库文章行可点击进入详情页。
- [x] 详情 URL 可直接刷新或后退返回。
- [x] 内容页显示当前 active snapshot 的章节与 blocks。
- [x] 版本页显示历史版本并标记当前活动版本。
- [x] 技术信息默认不在首屏，集中展示内部 ID 和版本。
- [x] 文档不在 active snapshot 时返回明确 404，不回退到登记库。
- [x] 后端详情 API、Vue 类型检查和生产构建通过。
