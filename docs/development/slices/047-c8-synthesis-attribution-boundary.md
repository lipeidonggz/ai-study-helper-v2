## 控制契约

### 背景与失败场景

- 触发问题：c8 的题目要求综合两篇文章形成整体图景，R3 也要求跨文章归并；但 X2 要求所有概括两篇的名称或口号必须同时来自两篇，导致“环境工程 + 边界工程”等明确的自拟综合被判违规。
- 不处理时的用户损失：回答忠实区分两篇观点并给出原创分析框架时仍会失败，评测奖励机械分段，抑制用户真正需要的综合能力。
- 现有流程为什么不足：X2 没有区分“声称某篇原文这么说”和“明确声明这是综合后的新概括”。
- 本切片负责什么：修订 c8 X2，使错误归属仍被拦截，明确标注的自拟综合合法；复用冻结答案重判。
- 本切片不负责什么：不放宽 R1/R2/R3，不改问题，不重跑 Agent，不修改判官提示词。

### 用户可观察目标

同一批 c8 冻结答案在新 X2 下重新判定；原有 c8 case revision 和 judgment 保留。

### 核心不变量

1. 把仅属于一篇文章的原文术语错误归因给两篇或另一篇，仍判 X2 违规。
2. 明确写成“综合两篇后的概括”“分析框架”或“类比”的自拟措辞，不因未逐字出现在原文中而违规。
3. 综合措辞中的组成概念仍须归属正确。
4. R2 的概念覆盖要求保持原样。

### 明确禁止

- 不得删除 X2。
- 不得把作者自拟总结自动认定为原文口号。
- 不得在本次修订中放宽 R2 或隐藏其唯一失败。
- 不得重跑 Agent 生成新答案。
