## 控制契约

### 背景与失败场景

- 触发问题：候选列表适合按对象浏览，但不能帮助用户沿原文顺序判断关键内容是否被覆盖。
- 不处理时的用户损失：用户需要在候选与原文之间来回查找 block，容易漏看整段未关联候选的内容。
- 本切片负责：completed run 中的原文顺序视图、block 到候选的确定性引用映射和双视图切换。
- 本切片不负责：判断某个未关联 block 是否一定构成漏提，或自动生成质量分。

### 用户可观察目标

用户可以选择 run 范围内的一篇文档，按 block 顺序阅读原文；每个 block 右侧显示引用它的
候选，并且可以只筛出没有关联候选的原文块。

### 核心不变量

1. 原文顺序来自 run 绑定 snapshot 的真实 blocks，不根据候选重新排序。
2. 左右关联只使用候选已有的 `source_block_ids`，不使用文本相似度或共现猜测。
3. “未关联候选”不得显示成“漏提”或“失败”。
4. 用户可切换文档、筛选未关联块，并从关联候选打开原位详情弹窗或加入质量校验基准；
   弹窗关闭后保持当前原文位置和视图状态。
5. 用户可以在“原文／中文”之间切换；中文模式按需补齐当前文档内尚未缓存的英文块，
   并始终保留查看原文的入口。
6. 同一候选引用多个 block 时，首次出现展示完整卡片，后续只展示“也引用了本段”的
   紧凑提示，不丢失多 evidence 关系。
5. 翻译只作为原文辅助阅读，不改变覆盖关系和候选身份。

### 失败语义

| 场景 | 用户看到什么 | 系统保留什么 | 是否可恢复 |
| --- | --- | --- | --- |
| 文档 blocks 读取失败 | 可操作错误和空状态 | 当前 run 与候选 | 重试或换文档 |
| run 未完成 | 不显示原文覆盖视图 | 当前运行状态 | 完成后再看 |
| block 没有关联候选 | 中性“未关联候选”说明 | 原文不变 | 用户人工判断 |
| block 已有翻译 | 默认折叠，可展开中文 | 原文优先 | 是 |

### 明确禁止

- 不用近似文本匹配补造 block 到候选的关系。
- 不把未关联 block 自动计为漏提。
- 不让双栏变成互不关联的两个滚动列表。
- 不在查询视图时隐式调用翻译或其他模型。

## 输入与输出

- 输入：completed Preview Run、snapshot ID、文档 ID、完整 blocks、候选及其 source block IDs。
- 输出：按原文顺序对齐的 block／候选双栏；文档和未关联块筛选结果。

## 已知风险与后续

- 未验证项：长文档中的滚动和分节粘性体验、真实大块内容的双栏行高。
- 接受的风险：首版按 block 对齐，不显示原文章节树的完整折叠导航。
- 后续待办或 ADR：若长文档体验不足，再增加章节目录和 block 折叠，不改变关联语义。

## 停止与推翻条件

- 无法稳定读取 run 对应 snapshot 的完整 blocks；
- 需要靠文本相似度才能建立 block 到候选的关联；
- 双栏无法在普通窗口宽度保持可读。
