## 目标

把 008 的后台任务 API 接到产品页面，让用户能提交多个本地文件／公开 URL，观察入库阶段和进度，暂停、恢复、取消任务，并在完成后确认当前知识库实际包含哪些文章、最近做过哪些操作以及每次操作的结果。产品页面通过主导航拆成知识库、入库、操作记录和设置四个工作区，不再把所有功能堆在一条长页面上。

## 输入与输出

输入：

- 多文件选择或 URL 输入；
- 已配置的 embedding Key；
- 当前后台任务状态和当前 collection pointer。
- 已持久化的历史入库任务。

输出：

- 来源队列；
- 当前任务卡片：状态、阶段、完成数、失败清单；
- 暂停／恢复／取消操作；
- 成功后的 snapshot；
- 当前知识库文章清单：标题、来源、版本、章节数和 block 数；
- 最近 20 次入库记录及逐来源结果。
- 可刷新和后退的主导航位置；入库工作区再分为批量入库和单篇预览。
- 可全量清空本地知识库并恢复为空知识库状态的高危操作入口。
- 单篇预览确认后可复用原 job artifacts 完成文档保存、embedding、索引和 collection 发布。

## 不包含

- 历史任务清理、分页、搜索和跨重启自动恢复当前任务句柄。
- 检索和对话入口。
- 文档删除、标题编辑和跨来源合并。
- 并发任务控制；后台任务仍按 008 的串行 worker 执行。

## 验收条件

- [x] 可添加多个本地 HTML 文件和公开 URL，并移除来源。
- [x] 没有 embedding Key 时不能启动后台任务，并显示明确提示。
- [x] 启动任务后立即显示 queued／running 状态和阶段进度。
- [x] 任务轮询显示已完成数、失败数和失败来源。
- [x] running／queued 任务可以暂停，paused／interrupted 任务可以恢复。
- [x] 活动任务可以取消。
- [x] 成功任务显示 snapshot ID 和当前 collection 文档／章节／block 汇总。
- [x] partial collection 显示“部分入库”标记。
- [x] 当前知识库显示每篇文章的标题、来源、版本、章节数和 block 数。
- [x] 连续两批成功入库后，活动知识库保留两批文档的并集。
- [x] 同一文章重新导入时只保留一个 `doc_id`，新版本替换旧版本。
- [x] 最近入库记录在刷新或重启后仍可读取，并显示逐来源成功／失败结果。
- [x] 桌面窗口启动后自动最大化。
- [x] 主导航可切换知识库、入库、操作记录和设置；入库工作区可切换批量入库和单篇预览。
- [x] 导航位置写入 URL hash，刷新和浏览器后退不会总是回到同一个长页面。
- [x] 设置页提供“清空知识库”，必须输入“清空知识库”确认后才允许执行。
- [x] 清空会移除文章、版本、任务、发布记录、活动快照、artifacts、trace 和数据库备份，并保留模型设置。
- [x] 有后台任务运行时拒绝清空，避免并发写入损坏状态。
- [x] 单篇预览点击“开始入库”后会生成操作记录，并真正出现在当前知识库中。
- [x] 单篇入库复用已确认的预览产物，不重新抓取文件或 URL。
- [x] Vue 类型检查、生产构建和完整质量门通过。
