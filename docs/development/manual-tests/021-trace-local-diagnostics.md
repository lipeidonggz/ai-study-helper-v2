## 验收项

- [x] 完成一次问答后，可从结果或诊断入口打开对应 trace。
- [x] trace 时间线显示轮次、模型调用、工具调用、预算、token、耗时和最终状态。
- [x] 应用重启后，刚完成的 trace 仍可查看。
- [x] `full` 模式可打开渲染提示词、工具 payload 和回答 artifact。
- [x] 最近运行列表用问题前段作为名称。
- [x] `metadata` 模式不逐条展示 omitted artifact，只显示省略数量汇总；除问题前段外，提示词、工具正文和回答正文不可查看。
- [x] `off` 模式完成问答后不新增 trace 记录，也不生成 trace 目录。
- [x] trace 目录不可写或队列满时，问答仍成功，界面明确显示 trace 降级。
- [x] 删除或损坏派生索引后，可从 trace 文件重建并重新查看。
