# 020 · 流式问答工作台人工验收

## 验收项

- [x] “问答”导航可以提交问题，问题与回答区域清晰分离。
- [x] 等待期间显示阶段或工具状态，但不显示 Thought、原始 Action、Observation 或工具 JSON。
- [x] 固定状态区实时显示输入、输出 token；流中标记为估算，调用完成后切换为实际值。
- [x] 最终答案正文逐步出现，停止或完成后不重复渲染。
- [x] Markdown 标题、列表、粗体、代码和表格正确显示，模型输出中的原始 HTML 不会执行。
- [x] 来源区默认折叠；点击正文数字角标后自动展开、滚动并高亮对应来源卡片。
- [x] 来源卡片默认只显示标题、来源和章节，点击后才展开摘要及文档详情入口。
- [x] 无法匹配的引用显示“来源未匹配”提示，不再出现无响应问号。
- [x] 点击来源卡片中的“查看文档详情”后，自动定位到对应原文 block 并突出显示。
- [x] 点击“停止”后界面进入已取消状态，已生成内容保留。
- [x] 断线后界面明确显示已中断；续传时不重复正文，无法续传时不自动新建运行。
- [x] 预算、模型失败和快照不可用有明确、可操作的错误提示。
- [x] 部分回答不会被标记为完整回答。
