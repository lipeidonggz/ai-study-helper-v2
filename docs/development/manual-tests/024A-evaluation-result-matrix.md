## 验收项

- [x] 历史结果中可以选择已判定 run 并打开“结果矩阵”。
- [x] 顶部 run 汇总显示 case 状态分布、有效样本、X 红线、token、模型调用、工具调用和耗时。
- [x] 类别层只包含该类别 case，并能看到类别汇总。
- [x] case 层显示 N/K、有效样本、pass／fail／pending 和 X 红线。
- [x] 展开 case 后看到按开始时间排序的样本，序号稳定。
- [x] attempt 层显示状态、token、模型／工具调用、耗时和 trace 状态。
- [x] 点击“查看判定”在结果矩阵上方打开对应 attempt 的判定弹窗，不切换页签。
- [x] 判定弹窗展示本次冻结问题、R／X、每条 R／X 的完整金标准、判定原因和跨项检查。
- [x] 判定弹窗内容可以独立滚动，滚轮不会带动主窗口上下滚动。
- [x] 点击“运行轨迹”在结果矩阵上方打开对应 attempt 的 trace 弹窗，不切换页签。
- [x] 轨迹弹窗支持调用树、运行内容和 artifact 查看，关闭后回到原矩阵位置。
- [x] 轨迹弹窗内容可以独立滚动，滚轮不会带动主窗口上下滚动。
- [x] 调用树中的 `tool.call` 直接显示工具名称和参数；参数过长时截断，鼠标悬停可查看完整参数。
- [x] 判定未启动时显示空状态；判定 pending 时不显示虚假通过。
- [x] 页面显示与 023B case aggregate 的质量结果一致。
