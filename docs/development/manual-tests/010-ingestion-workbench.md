# 010 · 入库工作台人工验收

- 状态：待补充人工验收
- 日期：2026-10-21
- 关联切片：[010 入库工作台](../slices/010-ingestion-workbench.md)

## 验收项

- [x] 工作台初始显示空队列，“开始后台入库”不可用。
- [x] 添加、移除本地 HTML 文件；恰好一个来源时启动按钮可用。
- [x] 单本地文件完成后显示 `1 / 1`、snapshot ID 和当前知识库汇总。
- [x] 多文件任务进入“入库中”后可以暂停；暂停期间进度不前进。
- [x] 恢复后任务继续并成功完成。
- [x] 活动任务可以取消；取消后不发布新 snapshot，旧 collection 继续显示。
- [x] partial 任务显示成功数、失败数和失败来源。
- [x] partial 任务发布 snapshot，并显示“部分入库”。
- [x] 公开 URL 来源可以入队并完成入库。
- [x] 验收中发现的英文失败消息已改为按错误码显示中文。
- [ ] 当前知识库按文章显示标题、来源、版本、章节数和 block 数。
- [ ] 连续完成两批入库后，文章总数和文章清单保留两批并集。
- [ ] 最近入库记录显示时间、来源数、成功／失败数、状态和逐来源结果。
- [ ] 刷新页面或重启应用后，当前文章清单和最近入库记录仍可读取。
- [ ] 重新启动桌面应用后，主窗口自动最大化。
- [ ] 主导航可在知识库、入库、操作记录和设置之间切换，且一次只显示一个工作区。
- [ ] 入库工作区可在批量入库和单篇预览之间切换。
- [ ] 刷新页面或使用浏览器后退后，仍停留在对应工作区。
- [ ] 设置页输入错误确认短语时，“确认清空全部数据”不可用。
- [ ] 输入“清空知识库”后可执行清空，知识库文章和操作记录均变为空。
- [ ] 清空后 embedding Key 和模型设置仍然保留。
- [ ] 后台任务运行时不能清空知识库，并显示明确原因。
- [ ] 单篇预览点击“开始入库”后，操作记录出现对应任务并显示处理进度。
- [ ] 单篇任务成功后，文章出现在当前知识库，任务状态为已完成。
- [ ] 列表项内含 HTML 注释的页面可以正常预览和入库，注释内容不会进入正文。
