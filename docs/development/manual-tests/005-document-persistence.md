# 005 · 文档保存人工验收

- 状态：已完成（2026-10-21）
- 对应切片：[005 SQLite 文档身份与版本登记](../slices/005-sqlite-document-registry.md)
- 目的：验证预览后保存、正式版本展示和重复保存幂等

## 主流程

1. 启动应用并导入 `backend/tests/fixtures/complex-article.html`。
2. 在预览区点击“保存到知识库”。
3. 检查保存结果：
   - 显示以 `doc_` 开头的文档 ID；
   - 显示“版本 1”和“新文档”。
4. 关闭并重新启动应用。
5. 再次导入同一文件并保存。
6. 检查结果显示“版本 1”和“已有版本”，文档 ID 不变。
7. 关闭应用，确认 sidecar 进程和端口退出。

## 自动化故障注入

以下场景由 `test_persist_rejects_missing_preview_artifact` 自动验证，不要求人工修改应用私有目录：

1. 完成预览后删除对应 job 目录中的 `extracted.json`。
2. 请求保存。
3. 预期返回 `job_artifact_missing`，不生成保存成功结果。
