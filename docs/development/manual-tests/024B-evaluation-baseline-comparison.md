# 024B · 基线与比较人工验收

- 状态：已完成
- 日期：2026-10-24
- 关联切片：[024B 基线管理与跨 run 比较](../slices/024B-evaluation-baseline-comparison.md)

## 验收项

- [x] 完整正式 run 显示“设为当前基线”入口，并展示 reviewer／reason 输入。
- [x] 不完整、部分封存、pending 或 exploratory run 不能设为基线，原因可读。
- [x] 设置成功后，该 suite＋run type 显示当前基线信息。
- [x] 将另一个完整 run 设为基线后，当前基线切换，旧基线仍可从历史记录找到。
- [x] 人工改判后重算 ResultMatrix，再次设置同一 run 为基线时追加新基线；重复设置同一结果不新增，旧基线仍保留。
- [x] 同场 run 可以打开“基线比较”，看到 run 级和 case 级差异。
- [x] case 差异能区分通过／失败／pending 翻转、X 红线、token 和调用量变化。
- [x] collection snapshot、suite revision、case 集合或运行策略不一致时显示“环境已变化，仅供排查，不可直接归因”和具体原因。
- [x] 无当前基线时比较入口不可用，并有明确说明。

## 人工证据

- 2026-10-24 负责人完成 snapshot 不同的跨场验收：界面显示 `collection_snapshot_changed`，case 结果无翻转，但 token、工具调用和耗时变化仍被独立展示并标记为不可直接归因。
- 2026-10-24 负责人确认切换当前基线后，旧基线仍可从历史记录找到。
- 2026-10-24 负责人确认无当前基线范围显示“尚无基线”和设置基线后才能比较的明确说明。
- 2026-10-24 负责人接受人工改判后的重新基线化由自动化测试覆盖；测试验证追加新基线、相同结果幂等和旧基线不变。
