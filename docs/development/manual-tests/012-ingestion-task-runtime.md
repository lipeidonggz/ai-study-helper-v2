# 012 · 入库任务运行与恢复人工验收

- 状态：已完成
- 日期：2026-10-22
- 关联切片：[012 入库任务串行执行与中断恢复](../slices/012-ingestion-task-runtime.md)

## 验收项

- [x] 不刷新页面，在第一个任务运行中通过正常界面创建第二个任务；第二个显示“排队中”。
- [x] 页面刷新后，运行中和排队中的任务仍显示在持久任务队列里。
- [x] 应用在一个任务运行期间关闭并重新打开后，操作记录显示该任务“已中断”。
- [x] 可以从操作记录恢复该中断任务，并继续显示处理进度。
- [x] 可以从操作记录取消中断或排队任务。
- [x] 一个任务部分来源失败时，当前任务卡片显示“部分入库”。
- [x] 同一任务在操作记录中也显示“部分入库”。
- [x] 部分失败任务的进度视觉不会显示成全部绿色成功。

## 人工证据

- 用户截图确认 `complex-article.html + empty-content.html` 任务顶部显示“部分入库”，进度条为警告色，失败来源 2 显示 `no_extractable_content`。
- 用户截图确认 7 来源任务在应用重启后显示“已中断”，并出现“恢复／取消”操作。
- 用户恢复该任务后继续到 `7 / 7`，最终为成功 6、失败 1，活动快照发布；当前卡片与历史均显示“部分入库”。
- 用户确认正常界面可以在前一个任务运行时继续创建新批次，新任务进入持久队列并显示为排队。
- 用户确认取消排队任务后，该任务从活动队列移除并进入操作记录，正在运行的任务不受影响。
- 用户确认页面刷新后，运行中与排队中任务仍从持久队列恢复显示。
