# 013 · 入库工作台交互优化人工验收

- 状态：已完成
- 日期：2026-10-22
- 关联切片：[013 入库工作台交互优化](../slices/013-ingestion-workbench-ux.md)

## 验收项

- [x] 顶部品牌区高度明显缩小，首屏能直接看到工作区。
- [x] 宽窗口下“新建批次”和“任务监控”为双栏布局。
- [x] 窄窗口下两栏自动变为单列。
- [x] 运行中任务显示当前来源名和已用时间。
- [x] 排队任务显示真实的排队位置。
- [x] 队列行可直接暂停、恢复或取消，且只显示允许操作。
- [x] 有任务运行时仍可正常创建下一条任务。
- [x] 队列、详情和操作记录中的状态一致。

## 人工证据

- 用户截图确认顶部标题缩为单行，1920 宽窗口首屏同时显示导航、新建批次、任务队列和当前知识库摘要。
- 用户确认运行任务显示当前来源和已用时间，第二任务显示 Q1，队列行提供直接操作，左侧新建表单保持可用。
- 用户确认窄窗口下新建批次和任务监控自动变为上下单列，按钮、状态和来源路径无重叠。
