## 状态口径

| 状态 | 含义 |
| --- | --- |
| 候选 | 已识别，但尚未确认是否值得做 |
| 已接受 | 方向确认，尚未进入具体切片 |
| 已排期 | 已进入明确的后续切片计划 |
| 进行中 | 正在当前开发切片中实现 |
| 已完成 | 验收通过并已进入基线 |
| 已拒绝 | 明确不做，保留原因供以后复查 |
