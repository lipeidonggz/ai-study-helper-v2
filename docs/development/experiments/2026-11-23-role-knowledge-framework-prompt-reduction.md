# 角色知识框架提示词减法实验

- 状态：进行中，待人工审核
- 日期：2026-11-23
- 领域与角色：`AI Agent / 系统架构师`
- 模型：`deepseek-flash`
- 采样：温度 `0`，thinking 开启
- 基础逐轮回放：每个候选 3 次独立调用；S5／S7 另行追加五次同口径覆盖复核（见 §5.8）
- 关联设计：[16 · 使用角色驱动的领域知识组织](../../design/16-使用角色驱动的领域知识组织.md)

## 1. 实验目的

当前新版 §4.6.4 提示词生成的知识框架普遍只有 100～200 个节点，且多数分支在第二层结束；旧版 `v2-expanded` 在包含“至少三层”约束时生成 415 和 546 个节点，去掉该约束后仍生成 385、368 和 208 个节点。

本实验以旧版 `v2-expanded` 为底稿，逐轮删除明显不合理或相互冲突的约束，再逐轮补充必要契约。每轮只改变一个语义点，观察改动是否同时改善结构展开和知识覆盖，避免把多个变化混在一起后无法归因。

本实验不把 AI Agent 的具体知识类别写入生成提示词。AI Agent 检查清单只用于生成后的离线覆盖评审；最终候选还要在未参与调优的领域和角色上做一次泛化回放。

## 2. 固定实验口径

每轮使用完全相同的领域、角色、模型和输出上限。每个版本独立运行 3 次，不挑选“最好的一次”作为版本结果；结构结果同时记录中位数、范围和三次逐轮明细。

结构指标：

- 一级节点数；
- 总节点数；
- 叶节点数；
- 各层节点数；
- 叶节点层次分布；
- 重复标题；
- 输出 token 与耗时；
- 结构校验结果。

覆盖评审使用固定 14 项 AI Agent 知识检查清单，每项标记为：

- `covered`：存在明确、可独立检索的主路径，主要子问题已展开；
- `partial`：只覆盖部分内容，或仅分散在宽泛节点和描述中；
- `missing`：没有可用主路径。

固定检查清单：

| ID | 覆盖范围 |
| --- | --- |
| C01 | 工作流式自动化、工具增强 LLM 应用与 Agent 的边界 |
| C02 | Agent 适用性，以及确定性代码、规则流程、人工处理的职责边界 |
| C03 | ReAct、Router、Supervisor、黑板、流水线等架构模式及权衡 |
| C04 | 模型能力边界、选型、路由、更新与漂移 |
| C05 | 规划失败、不确定性、反思与重规划 |
| C06 | 工具副作用、动作空间、权限、不可逆操作与幂等 |
| C07 | RAG 的切分、索引、重排、引用溯源与新鲜度 |
| C08 | 事件、队列、调度、人工节点与业务流程集成 |
| C09 | 轨迹质量、LLM Judge、回归评测与评测偏差 |
| C10 | 幻觉、循环、超时、熔断、补偿与状态一致性 |
| C11 | 隐私、同意、删除、数据驻留与第三方模型 |
| C12 | API 网关、密钥、网络隔离与 Serverless 部署 |
| C13 | 协议版本、兼容性、标准演进与供应商锁定 |
| C14 | 知识建模、编目、索引运维与数据血缘 |

该清单只用于验证，不进入任何候选提示词。

## 3. 判断原则

不以“节点越多越好”作为唯一结论。一个版本要进入下一轮或成为候选，必须同时满足：

1. 三次结构有效，不得靠截断、静默重试或修改断言获得通过；
2. 不能稳定退化为只有两级、且二级叶节点大量承载复合知识；
3. 固定 14 项不能出现比上一轮更严重的系统性退化；
4. token 成本增长应能换来可观察的覆盖收益；
5. 提示词保持领域无关，不得包含 AI Agent、角色任务或测试问题的具体知识类别。

任何一轮只要出现新的高危害退化，就先回退该单点，再讨论替代写法。

## 5. 逐轮实验记录

后续每轮按以下结构追加：

- 唯一改动；
- 修改理由与语义根因假设；
- 完整提示词差异和 SHA-256；
- 三次结构结果；
- 覆盖评审；
- 结论：保留、回退或继续观察。

### 5.1 S2：知识类型名称不得证明叶节点已原子

唯一改动：在旧版第 8 条末尾增加类型名称与拆分优先级。

```diff
 8. 叶节点只能表达一个知识对象、类型体系、机制、过程、条件、方法、判据、模式或案例类别；不得把多个并列范围用“与”、顿号或其他方式合并成一个叶节点。
+ 上述知识类型只描述叶节点的表达形式，不能作为停止拆分的依据；即使节点可以被称为类型体系、机制、过程或案例类别，只要其中仍有可分别检索的子范围，就必须继续拆分。
```

提示词 SHA-256：`6a2dc3c9ade08d146f47ff4f54f1f6fdb76edcbc60ec649f3ff5108c856f962e`

修改理由：旧版第 7 条要求继续拆分复合范围，第 8 条又允许“类型体系、机制、过程、案例类别”作为叶节点。模型可以把复合内容改名为一种合法类型来绕过拆分。本改动测试该歧义是否是结构波动和覆盖不足的来源。

### 5.2 S3：生成阶段不预判证据覆盖

唯一改动：生成阶段只判断知识主题是否可独立检索，不再要求模型在尚无证据时预判能否独立判断证据覆盖。

```diff
-6. 必须逐层展开知识范围，直到叶节点成为单一、可直接检索和独立判断证据覆盖的知识主题。
+6. 必须逐层展开知识范围，直到叶节点成为单一、可直接检索的知识主题。

-7. 一个节点只要包含两个或更多可以分别命名、分别检索或分别判断覆盖的知识范围，就必须继续拆成子节点。
+7. 一个节点只要包含两个或更多可以分别命名或分别检索的知识范围，就必须继续拆成子节点。
```

提示词 SHA-256：`55efe8ded0419cad66db093b46f22896102fbdbcbc073989fbbceff510b65368`

修改理由：初始生成阶段没有知识库和 block，无法验证“以后能否独立判断证据覆盖”。该短语可能让模型猜测后续编译能力，而不是判断领域知识自身的原子性。移除后观察是否减少无依据拆分或反而导致过度合并。

### 5.3 S4：说明与排除项职责分离

唯一改动：基于 S2，从节点描述中移除“主要边界”的职责，明确 `exclusions` 只记录确实容易混淆的相邻主题，并允许为空。

```diff
-5. 每个节点必须给出描述，说明该节点应覆盖哪些知识内容以及主要边界。
+5. 每个节点必须给出描述，说明该节点应覆盖哪些知识内容；exclusions 仅记录确实容易混淆的相邻知识主题，可以为空，不要求每个节点填写。
```

提示词 SHA-256：`a09665f599797ccbca9ad0b787df6e5cf5fb278e8c83d774d9e98769c7f2e945`

修改理由：旧版同时要求 `description` 写主要边界，又要求 `exclusions` 记录相邻但不属于该范围的内容，两个字段可能在承担同一职责。本改动测试去除重复职责能否减少无意义排除项，同时保持知识展开质量。

### 5.4 S5：删除单次调用中不可执行的跨次组织约束

+9. 展开后的知识范围必须足以覆盖该角色在领域中的主要知识疆域。

#### 5.8.4 判定

这次五次回放不支持“S7 标题规则整体优于 S5”。S7 的收益集中在标题可识别性和两个分支（C04、C10）的稳定性，但覆盖均值没有提高，覆盖下限从 6 降到 4，并引入一次整类缺失；同时它用更高 token 和更长耗时生成了更少的节点。

因此当前决策保持 S5 为生成候选，S7 的标题条款不整体替换 S5。标题独立识别应继续作为生成后的 §4.6.5 `unclear_title` 审查项，或后续只抽取“泛化类别词必须带对象限定语”这一窄规则单独实验；不能把整套 S7 标题规则当作提升覆盖率的手段。

#### 5.8.5 机制分析：单次生成同时承担发散与收敛

直接比较两次实际调用中的 `prompt` 后，确认 S5 与 S7 只差第 4 条标题规则，没有混入其他提示词变化。因此结果差异不能用“提示词还改了别的部分”解释。不过，这条规则不是只影响最终名称格式；它参与每个节点的拆分、停止和保留判断，会改变整棵树的生成路径。

可观察的结构代理指标如下：

| 指标 | S5 五次中位数 | S7 五次中位数 | 变化 |
| --- | ---: | ---: | ---: |
| 平均节点标题长度 | 5.57 字 | 7.71 字 | +38% |
| 平均节点 description 长度 | 25.00 字 | 28.22 字 | +13% |
| 标题包含比较、差异、边界、权衡或区别的节点数 | 12 | 9 | -25% |

五次运行中，S5 只有一次在第二层留下叶节点；S7 有三次在第二层留下叶节点，分别为 12、59 和 13 个。这与“平均标题更长、边界／比较节点更少、总节点更少”同时出现，说明模型不只是在重命名叶节点，而是在更早的位置把较细范围合并成了更容易独立命名的宽节点。

可能的机制是：树形结构原本由父路径承载上下文，子标题只需要表达与父节点的差异；S7 却要求子标题脱离父路径后仍能独立识别，同时又不允许机械重复父路径。当模型难以同时满足“独立、简短、不重复父路径、描述完整”时，最省力的策略就是减少细分、提前停止展开，或者把细节压入 description。S7 的标题质量收益是真实的；覆盖和结构退化不是同一个收益的反面噪音，而是同一个约束对节点形成决策的副作用。

这也会影响覆盖统计本身。固定 14 项要求存在明确、可独立检索的主路径；当 S7 把一个原本会分成多个叶节点的范围压缩成宽节点时，知识可能仍留在 description 中，但会从 `covered` 变成 `partial`。因此这次结果不能解释为“模型完全丢失了同样多的知识”，更准确的解释是“知识被发现后，没有继续形成足够细的可检索结构”。

更上层的根因是单次调用同时承担了发散和收敛两类工作：

- 发散：尽可能发现该角色需要掌握的知识疆域，不漏掉分支；
- 组织：决定一级划分、父子关系和拆分深度；
- 收敛：判断叶节点原子性、去重、写 exclusions，并保证全局覆盖；
- 表示与自检：为每个节点生成可独立识别的标题和 description，并逐节点检查这些标题是否满足契约。

这些目标的优化方向彼此制约。S5 的五次节点数已经横跨 360～734，说明单次生成本身已有较大不稳定性；S7 再增加全局标题一致性要求后，模型更容易采用“少拆、少写关系节点、用较长 description 承载细节”的低风险策略。温度 0 不能消除远端推理过程的结构波动，所以这里不能宣称某一轮的单个 `M` 必然只由标题条款造成；但节点规模、标题长度和提前叶片化的同向变化足以支持“该条款显著改变了生成策略”这一判断。

因此设计上不应继续要求同一次生成同时完成“尽量全地发现知识”和“每个标题都达到最终展示标准”。更合适的职责边界是：

1. 知识框架生成阶段以覆盖和合理展开为主，不承担最终标题规范化；
2. 结构审查阶段检查漏项、错误合并、过早叶片化和覆盖缺口；
3. 标题审查或重写阶段只改表示，不重新决定知识边界和树结构。

该分析是基于现有结构指标与覆盖结果的机制假设，不是单变量因果实验的最终证明；它已经足以支持当前阶段不把 S7 整体并入生成提示词。

## 6. 最终决策

### 6.1 泛化回放

为避免只在 AI Agent 和系统架构师上过拟合，使用未参与调优的“现代营养学／注册营养师”回放 S5。该组只检查结构、重复和一级目录的领域相关性；固定 14 项是 AI Agent 专用清单，不套用到营养学，也不调用任何覆盖审查提示词。

| --- | ---: | ---: | ---: | ---: | --- | ---: | ---: |
| 1 | 13 | 500 | 403 | 4 | 13 / 76 / 361 / 50 | 26,577 | 0 |
| 2 | 14 | 401 | 304 | 4 | 14 / 79 / 286 / 22 | 28,754 | 0 |

三次都自然展开到四层，没有出现由提示词带入的 Agent、工具、模型路由或软件部署词汇。三次一级目录都包含营养代谢基础、宏量／微量营养素、营养评估与诊断、临床营养、生命周期营养、公共营养、咨询与行为改变、食品服务、研究方法与专业规范等主分支；组织方式和边界划分有差异，但展开后的知识范围高度一致。

### 6.2 候选结论

当前候选为 S5：

- 以旧版 `v2-expanded` 为底稿；
- 删除“整套框架不得少于三层”；
- 明确知识类型名称不能证明叶节点已经原子；
- 删除单次无状态生成中不可执行的“组织方式不必跨次固定”；
- 保留“展开后的知识范围必须足以覆盖该角色在领域中的主要知识疆域”。

S0 的同口径回放表明，“三次全部达到三层”和“三次均无 `missing`”不是 S5 独有的收益。S5 相对 S0 的剩余优势只有两点：固定 14 项中 `covered` 的中位数从 6 提高到 7；提示词不再要求一个没有领域依据的固定最低层数，也不再包含单次无状态调用无法执行的跨次组织约束。S5／S7 的五次追加回放进一步表明，S7 的强标题约束没有提高覆盖均值，反而把覆盖下限从 6 降到 4，并增加 token、耗时和方差。单次生成仍存在明显波动，因此这项差异目前只能作为探索性候选依据。

选择 S5 作为候选的原因是：

1. 它保留了 S0 的自然多层展开和固定 14 项无整类缺失的覆盖下限，同时同口径 `covered` 统计略高；
2. 它删除了“整套框架不得少于三层”这一不可由知识本身证明的硬约束，允许不同领域自然停在合适深度；
3. 它删除了单次无状态调用中不可执行的“组织方式不必跨次固定”；
4. 它在未参与调优的营养学回放中自然展开到四层，且没有带入 AI Agent 或营养学专有提示词。
5. 在 S5／S7 各五次的追加覆盖复核中，S5 的平均完整项为 7.2、下限为 6，高于 S7 的 7.0 和 4；S7 的标题收益不足以抵消覆盖下限与生成成本损失。

已知局限：

- S5 相对 S0 的覆盖优势只有中位数 1 项，尚不能排除固定 14 项判定敏感性和生成波动；需要增加独立运行次数，并加入未参与调优的领域和角色复核；
- C07、C09、C11、C12、C13、C14 在 S0 中三次均为 `partial`，在 S5 中也仍有局部缺口，说明单次生成不能保证所有细分范围，需要多次生成、合并或后续任务覆盖补查；
- S5 原三次分别有 1、4、5 个重复标题；追加五次有 4、4、2、1、8 个，重复仍明显。S6 已证明用更长的生成期同一性规则处理重复会触发扁平化，因此重复更适合留到生成后的归并阶段；
- AI Agent／系统架构师上 S5、S7 各累计八次有效生成（原三次加追加五次），现代营养学／注册营养师上 S5 只有三次；领域和角色仍然很少，不能据此宣称方法已经稳定，进入产品设计前仍需在更多未参与调优的领域和角色上验证；
- 本次没有实现或调用覆盖审查模型。固定 14 项均由完整树的标题、描述和路径直接检查。
