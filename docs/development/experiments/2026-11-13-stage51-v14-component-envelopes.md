# 5.1 v14 分量信封与纯摘要协议实验

## 目的

验证多分量归并改为按分量嵌套响应后，是否能同时改善两项指标：

1. 完整编译成功率与结构恢复成本；
2. 术语入口和概念义项边界的跨回放稳定性。

本实验固定单篇快照与模型参数，不根据 c13-003 检索结果调整阈值或提示词。

## 方案

- 多草稿连通分量仍按输入字符和预计输出 token 双预算合批；
- 响应根对象为 `components`，每个分量单独返回局部 `groups`；
- 合法分量直接采用，只有模型响应可恢复失败的分量才单独重试；
- 根信封结构失败先重试原批次，耗尽后才退化为一请求一分量；
- 单草稿分量进入独立的纯摘要协议，不再伪装成归并任务；
- 供应商传输、上下文超限和反馈预算不足不触发拆分，避免放大一次基础设施故障。

编译契约版本为 `dual-entry-stage51-v14`、`stage51-induction-v13`、
`stage51-compile-v13`。

`length=<实际字符数>:max=240`，用于下一次真实失败诊断。

## 术语稳定性

5 张成功地图的术语集合两两 Jaccard 为 0.8865～0.9438，均值 0.9141；五图交集 238，并集 286。
v12 两张成功地图的 Jaccard 为 0.9158，因此本次没有观察到术语集合稳定性的实质提升。

预先观察的 15 个原文入口中，`environment layer`、`model layer`、`egress`、`containment`、
`sandbox`、`sandboxes`、`isolation`、`prompt injection`、`human-in-the-loop`、`gvisor`、
`hypervisor`、`seccomp`、`allowlist`、`workspace`、`vm` 在 5 张成功地图中均存在。

`checkpoint` 不属于本文的术语入口检查集。它来自此前 c13-003 的整体检索审查清单，被误带入本次
按原文术语核对的 16 词列表；26 个原文块中没有字面词 `checkpoint`，相关语义只以
`state directories`、`persistent workspace` 等形式出现。因此它不是本次术语抽取失败，也不能
归入 O1 的显式综合入口误拒。保留这项说明，仅用于防止再次把跨用例的隐含目标词当成当前文章的
缺失入口；5.1 不应在术语阶段补写原文不存在的锚点。

## 概念义项边界

信封协议改善了结构可靠性，但没有改善义项粒度稳定性，反而出现明显过拆信号：

| 指标 | v12 两次成功回放 | v14 五次成功回放 |
| --- | ---: | ---: |
| 概念义项数 | 269～272 | 285～303 |
| 一个术语对应多个义项的数量 | 2 | 15～20 |
| `claude` 的义项数 | 2～3 | 7～17 |
| `agent` 的义项数 | 1、5 | 2～5 |
| `workspace` 的义项数 | 1、3 | 1～2 |

抽查 v14 run5 的 `claude` 义项，摘要主要分别描述 Cowork 的 VM、EDR 可见性、出口代理、Code
沙箱、MCP 位置、风险分类和红队事件。它们属于围绕 `Claude` 的不同陈述或不同产品/运行机制，
不应被概括成同一个宽泛概念；当前结果更像把“该块关于 Claude 说了一件不同的事”当成新义项，
而不是判断词面所指的概念身份是否相同。

当前证据只能证明 v14 存在系统性过拆信号，不能单因子证明它由分量信封造成。v14 同时改变了
响应结构和单草稿摘要协议，下一步应把“身份成组”和“摘要生成”拆开检查，或在完全相同结构下只改
概念身份提示，才能归因。

## 结论

1. 分量信封值得保留：5 次成功运行中没有再出现跨分量结构错误，成功运行也不需要结构重试。
2. v14 还不能作为最终质量路径：整体完整成功率为 5／6，仍有摘要长度导致的阻断失败。
3. 性能与 v12 接近：总请求数约 98～109，归并请求 28～39；成功运行总耗时约 67～81 秒。
4. 术语集合稳定性与 v12 相当，没有明显提升；15 个原文关键入口在 5 次成功地图中稳定。
5. 概念义项边界明显变差：一词多义项数量和 `claude` 义项数大幅上升，说明“能稳定返回结构”
   不等于“能稳定形成正确概念身份”。

下一轮应优先保持分量信封，并把概念身份成组与摘要生成进一步解耦：先稳定每个词面的概念义项
分区，再按已确定分区批量生成摘要。这样既能让超长摘要只影响对应摘要任务，也不会借摘要协议改变
概念身份。该调整会改变当前“同一归并响应同时产出摘要”的设计，需要沛东确认后再实现。
