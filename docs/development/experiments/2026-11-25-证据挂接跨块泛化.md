## 1 实验目标

前序实验主要在 `b00008` 上迭代单叶挂接协议。该样本覆盖工具权限、人工审批、审批疲劳和沙箱，虽然已经形成 R2 并完成 253 叶、10 轮回放，但同一 block 参与了多轮提示词语义对齐，不能单独证明泛化能力。

本实验固定一个未参与 R2 调参的新 block，回答两个问题：

1. 当前一级树标题骨架初筛，是否会为该 block 保留足以承载相关原文证据的一级分支；
2. 在保留分支形成的叶节点候选集上，R2 的必挂召回、灰区支持、硬负例误挂和逐叶稳定性是否仍处于同一语义口径。

本实验首先验证提示词能否泛化，不因单个新样本的局部漏挂直接修改 R2。只有在新 block 上发现可跨知识身份复现的系统性误判，且 reason、原文和人工金标准能够共同支持语义根因时，才形成提示词修改假设，并回到 `b00008` 与新 block 同时回归。

## 3 固定原文

### 3.1 英文原文

```text
Examples of reasoning trajectories for knowledge-intensive tasks (e.g. HotpotQA, FEVER) and decision-making tasks (e.g. AlfWorld Env, WebShop). (Image source: Yao et al. 2023 ).
In both experiments on knowledge-intensive tasks and decision-making tasks, ReAct works better than the Act-only baseline where Thought: … step is removed.
Reflexion (Shinn & Labash 2023) is a framework to equip agents with dynamic memory and self-reflection capabilities to improve reasoning skills. Reflexion has a standard RL setup, in which the reward model provides a simple binary reward and the action space follows the setup in ReAct where the task-specific action space is augmented with language to enable complex reasoning steps. After each action $a_t$, the agent computes a heuristic $h_t$ and optionally may decide to reset the environment to start a new trial depending on the self-reflection results.
Illustration of the Reflexion framework. (Image source: Shinn & Labash, 2023 )
The heuristic function determines when the trajectory is inefficient or contains hallucination and should be stopped. Inefficient planning refers to trajectories that take too long without success. Hallucination is defined as encountering a sequence of consecutive identical actions that lead to the same observation in the environment.
Self-reflection is created by showing two-shot examples to LLM and each example is a pair of (failed trajectory, ideal reflection for guiding future changes in the plan). Then reflections are added into the agent’s working memory, up to three, to be used as context for querying LLM.
```

### 3.2 中文翻译

```text
图中展示了面向知识密集型任务（例如 HotpotQA、FEVER）和决策型任务（例如 AlfWorld Env、WebShop）的推理轨迹示例。（图片来源：Yao 等，2023。）

在知识密集型任务和决策型任务这两类实验中，ReAct 都优于去掉 `Thought: …` 步骤的纯行动基线。

Reflexion（Shinn & Labash，2023）是一个让 Agent 具备动态记忆和自我反思能力、从而提升推理能力的框架。Reflexion 采用标准的强化学习设置：奖励模型给出简单的二值奖励，动作空间沿用 ReAct 的设定，并通过加入语言来扩展任务特定的动作空间，从而支持复杂的推理步骤。每执行一个动作 $a_t$ 后，Agent 会计算一个启发式指标 $h_t$，并可以根据自我反思的结果，选择是否重置环境、开始新一轮尝试。

图中展示了 Reflexion 框架的示意图。（图片来源：Shinn & Labash，2023。）

该启发式函数用于判断一条执行轨迹何时效率低下，或何时包含幻觉，并据此决定是否应该停止。低效规划是指轨迹耗时过长却仍未成功。幻觉则被定义为：连续出现一系列相同的动作，并且这些动作在环境中导致相同的观察结果。

自我反思的生成方式是：先向大语言模型展示两个示例，每个示例都由一对内容组成，即“失败的轨迹”和“用于指导未来计划调整的理想反思”。随后，这些反思会被加入 Agent 的工作记忆，最多保留三条，作为之后查询大语言模型时的上下文。
```

## 4 两阶段验证

### 4.1 一级树标题骨架初筛

当前主路径不是把 620 个叶节点直接交给单叶挂接，也不是复用 `b00008` 的 253 叶集合。先使用设计文档 §5.3 的同一提示词和输入结构，对 `b00007` 执行一级树标题骨架初筛：

- 输入全部 24 个一级分支的标题骨架；
- 一级标题用于识别大类，二、三级标题用于观察分支内部知识范围；
- 不输入一级描述、排除项和叶节点；
- 只排除整棵一级分支都明确无关的情况；
- 初筛结果不能直接形成证据挂接关系。

计划先用与 `b00008` 相同的 50 次独立回放检验结构稳定性和一级保留稳定性。评分同时记录：

- 结构合法次数；
- 每个一级分支的保留次数；
- 稳定保留、稳定排除和摇摆分支；
- 人工确认需要的一级分支是否被漏排。

保留一级分支后，宿主根据冻结知识森林收集其下全部叶节点，形成该 block 自己的候选叶节点集。候选集大小预计不同于 `b00008` 的 253 叶，实际结果必须由本轮产物确定。

一级树没有独立于叶节点的语义金标准。必须先确定哪些叶节点与 block 成立 `direct_support` 或 `weak_support`，再把它们的祖先一级分支推导为必须保留或应保护的集合。一级初筛的额外保留只记为候选范围与成本，不直接视为语义错误。

| `K01`、`K02`、`K03`、`K05`、`K11`、`K13` | 各 50/50 | 正例叶节点祖先，全部满足必保留条件 |

50 次调用全部结构合法、全部覆盖 24 个一级分支，且全部保留 6 个必保留一级树；没有关键分支漏排。逐次组合中，31 次恰好保留 6 个正例祖先，11 次额外保留 `K08`、`K12`，3 次再加入 `K22`，4 次再加入 `K18`、`K21`、`K22` 的不同组合，1 次只额外保留 `K12`。三级标题收紧了范围，但“控制循环、轨迹、反思、框架名称”仍会偶发抬高邻近一级分支；这属于候选层多保留，不是一级漏排，也不改变叶节点金标准。

为冻结下游单叶回放输入，本实验直接采用第一次有效三级骨架初筛运行（`run_index=1`）产生的一级分支，不做多数投票、归并或其他跨运行筛选。第一次运行恰好保留 `K01`、`K02`、`K03`、`K05`、`K11`、`K13`，共 6 个一级分支、149 个叶节点，其中 20 个必挂、7 个弱支持、122 个不支持。后续 49 次回放只用于观察稳定性，不参与候选集生成；即使某些运行额外保留其他分支，也不能改写 first-run 候选。

### 4.3 R2 单轮诊断结果

使用 first-run 候选集执行 149 次单叶调用，149 次全部完成、JSON 可解析且通过宿主结构校验。只有 11 个二元判断与初步金标准不一致：

| 类别 | 结果 |
| --- | ---: |
| 必挂 `direct_support` | 15/20，召回率 75.00% |
| 弱支持 `weak_support` | 2/7，灰区支持率 28.57% |
| 硬负例 `no_support` | 1/122 误挂，误挂率 0.82% |
| 硬精确率 | 93.75% |
| 硬 F1 | 83.33% |

本轮没有 JSON、字段、逐字引文或叶节点身份结构失败。错误结构明显偏向漏挂：5 个必挂漏判、5 个弱支持漏判，仅 1 个硬负例误挂。因此本轮不能支持“R2 在大范围误挂”的判断，更不能直接放宽提示词。

必挂漏判：

```text

K11.04.02 基准测试与基准选择
K13.03.04 失败类别到处理策略的映射原则
K13.04.01.01 重试机制
K13.04.04.02 幻觉缓解与输出验证机制
```

弱支持漏判：

```text
K02.03.01 上下文学习与少样本示例效应

K05.05.03 记忆检索与提取
K11.02.02 过程质量度量指标
K13.03.03 可恢复性判定条件
```

硬负例误挂：

```text
K03.06.01 上下文与知识约束下的规划
```

模型对 `K03.06.01` 引用了“反思指导未来计划变化，并把反思加入工作记忆作为后续查询上下文”，判为 `mechanism`。该条可能涉及金标准边界，而不是单纯提示词错误：原文确实把工作记忆中的反思用于后续计划，但没有直接讨论知识缺口、检索证据、上下文预算或信息不完整时如何调整计划粒度、查询顺序和假设使用。按照金标准先于模型输出的原则，本轮不根据该返回修改标注；留待负责人审查。

对 5 个必挂漏判的 reason 做初步归并，模型反复采用“原文只给出框架／实例／启发式，没有展开该叶节点要求的具体机制、指标、条件或映射原则”的理由。这可能同时包含两类问题：R2 对“实例可以支持上位知识身份”的边界仍偏严，以及部分待审叶节点描述本身要求了超出 block 细节的知识要素。当前证据不足以把某一种解释定为根因，因此本轮不修改 R2。

## 5 三档金标准

本实验使用设计文档 §5.6.1 的三档人工口径：

| 等级 | 含义 | 挂接策略 |
| --- | --- | --- |
| `no_support` | 不相关，或虽然主题相关但不能回答目标知识身份 | 不挂接 |
| `weak_support` | 部分支持、弱实例或处于可入可不入的灰区 | 可以挂接 |
| `direct_support` | 原文直接支持目标知识身份 | 必须挂接 |

金标准建立顺序固定为：

1. 根据冻结叶节点的完整身份边界，筛出可能相关的叶节点；
2. 逐项写下原文证据和定级理由；
3. 不在查看 R2 输出后再调整 `direct_support` 或 `weak_support`；
4. 负责人审核候选正例、灰区和需要特别说明的硬负例；
5. 冻结金标准文件并记录 SHA-256。

## 7 判定与停止条件

本轮不以单块达到 100% 必挂召回为目标，也不为新样本逐项增加措辞例外。出现以下情况时分别处理：

- 宿主结构错误、非法引文或解析失败：属于阻断性协议问题，先修复；
- 单个叶节点边界争议：记录为金标准或叶节点粒度问题，不立即改 R2；
- 同一类知识身份跨多个叶节点重复误判：形成语义根因假设，并与其他 block 对照后决定是否修改；
