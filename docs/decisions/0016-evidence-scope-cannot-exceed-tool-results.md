# 0016 · 证据覆盖范围不得小于结论影响范围

- 状态：已采纳
- 决定日期：2026-10-27
- 影响范围：Agent 证据使用、全局数量／结构结论、否定判断和回答可信度

## 背景

c3-001 的 Agent 多次只调用字面扫描获得单个命中块，却从该块的 `section_path` 推导整篇文档只有一个或一个一级章节。证据仅覆盖一条记录，回答却对完整目录作出结论。

## 决定

1. 工具结果只在其实际返回范围内提供证据。
2. 单条结果、Top-k、命中片段或局部枚举不能证明未返回对象不存在、集合唯一、排他或完整结构。
3. 需要全集、唯一、排他或完整结构结论时，必须取得目标范围的完整枚举。
4. 无法取得完整枚举时，应省略全局结论或明确声明未验证。
5. 不得使用模型知识补全工具尚未返回的范围。

## 后果

- 回答可能更保守，但不会把局部观察包装成全局事实。
- 该规则适用于检索、列表、目录、数量和否定判断，不依赖具体用例或领域词。

## 验证

- `chat-v9` 在 c3-001 N=10 中将结构 unknown 从 4 降到 1。
- 仍有 1 次完整结构结论越过单 block 证据，说明提示词不是确定性门禁。
- `chat-v10` 改为显式 `section_path`／`get_outline` fallback 契约后，N=10 为 48/50 criterion pass、1 citation unknown、2 quote invalid；未达到稳定修复目标。
